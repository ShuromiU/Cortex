## Why change anything

1. **Greenfield confirmed.** Read ledger, double-entry token P&L, negative-result
   cache, and dirty-set-keyed tool-output cache have no shipping competitor at any
   adoption level. Nearest neighbors: semantic-cache-mcp (hash verdicts, but only
   on its own MCP read path), tokensave (savings ledger, but single-entry — never
   debits its own injections).
2. **A window is closing.** Verified Read substitution became buildable-by-anyone
   when Claude Code v2.1.121 extended `hookSpecificOutput.updatedToolOutput` to
   built-in tools — a change driven by users asking for exactly this
   (anthropics/claude-code#32105). read-once and semantic-cache-mcp each ship half
   the mechanism. Native microcompact erodes the payoff but evicts by *age*, never
   by *verified content identity* — that distinction is the remaining edge.
3. **Parts of the plan already shipped elsewhere.** File cards are commoditized
   (Aider repomap, tokensave symbol graphs, DeepWiki, Cursor chunk cache).
   Subagent claim coordination ships natively (Claude Code Agent Teams
   lock-and-claim); conclusion-capture ships in Hindsight's plugin.

## Standing checks (not stories)

- **S-1: RESOLVED 2026-08-01 by Story 2.7.** Verify firsthand how native Claude
  Code auto-memory scopes across worktrees (research agents disagreed: shared
  vs. separate). **Answer: separate, and the disagreement was because both
  answers are half right.** Auto-memory lives at
  `~/.claude/projects/<key>/memory/`, where `<key>` is the *working-directory
  path* mangled. Observed directly: one repository with three linked worktrees
  holds four independent keys (`C--Claude-Code-repo-b` plus three
  `…--claude-worktrees-…` siblings), and only the main checkout carries a
  `memory/` directory at all. So **across worktrees it is separate**
  (fragmenting), while **across branches inside one worktree it is shared,
  because the path does not change on `git switch`** — confirming the original
  note that it has no branch *semantics*, and sharpening it: there is no branch
  dimension to have. Both halves are now in the README comparison section.
- **S-2:** Watch claude-mem, read-once, and semantic-cache-mcp releases for
  digest-verified substitution on native Read. If someone ships it, 4.5 drops
  from differentiator to parity — reassess its priority (build it anyway; ours
  composes with the ledger and P&L).
