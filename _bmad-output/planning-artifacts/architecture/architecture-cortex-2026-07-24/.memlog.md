- (decision) AD-2 two execution contexts. COLD path (Node, sole writer, owns SQLite) and HOT path (bash hook, read-only, Node-free, budget B-4a). Hot path may never write SQLite and never spawn Node. Prevents the read-refund feature from silently violating invariant N-4.
- (decision) AD-3 the digest index is a derived, regenerable, flat line-oriented file — the ONLY surface shared between hot and cold paths. Losing it is never data loss. Written only by cold-path flush, read only by hot path, greppable without a parser. Prevents two writers to one store and prevents the hot path needing SQLite.
- (decision) AD-9 session identity becomes (scope_key, agent_id) rather than scope_key alone. A hook payload carrying agent_id resolves to a CHILD session. This is the fix for the live defect where subagent tool calls were attributed to the parent because resolution keyed on cwd.
